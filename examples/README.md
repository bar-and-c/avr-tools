# Example code

Here are a few examples to show how you can set up projects for AVR.

[Pure AVR assembler](blinky_asm/README.md) is found in ```blinky_asm/```, [assembler with avr-gcc](blinky_gcc_asm/README.md) is found 
in ```blinky_gcc_asm/```, and [C code](blinky_c/README.md) in ```blinky_c/```.
